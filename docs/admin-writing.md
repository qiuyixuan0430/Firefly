# 写作台：公式与图片排版

在正文编辑器中，将光标放到要插入的位置，点击工具栏的“插入”（加号）菜单。

## 输入公式

- **独立公式**：适合分式、积分和多行推导。填写 LaTeX 后，公式在博客中独立成行并居中显示。
- **行内公式**：适合夹在文字中的短公式。填写后点击“插入”；再次点击正文中的公式标签可修改。

只填写公式内容，不需要填写两侧的 `$` 或 `$$`。例如：

```latex
E = mc^2
\frac{a}{b}
\int_0^1 x^2\,dx
\ce{H2O}
```

右侧预览会显示排版结果。语法有误时，预览会显示错误信息，原始公式仍可继续修改。公式以标准 `$...$` / `$$...$$` Markdown 保存到 GitHub，可以切换到源码模式编辑。

## 让图片居中

1. 从“插入”菜单选择 **图片排版（可居中）**。
2. 上传图片、从媒体库选择图片，或输入图片地址。
3. 在“图片对齐”中选择居中、左对齐或右对齐，默认为居中。
4. 按需填写替代文本、悬停提示和图片说明。右侧预览与博客前台使用相同的对齐方式。

已有的普通图片仍使用原来的编辑方式。如果要调整其对齐，复制原图片地址，在“图片排版（可居中）”中使用相同地址，再移除原图片块。图片不会被重复上传。

## 本地开发与部署

`pnpm dev`、`pnpm start` 和 `pnpm build` 会先从已安装的 `katex` 依赖生成写作台所需的脚本、样式和字体。生成文件位于 `public/admin/vendor/katex/`，无需提交。写作台不依赖第三方 CDN 加载公式资源。

组件回归检查：`node --import tsx --test scripts/test-admin-components.mjs`。

提交并推送这些代码到 GitHub 的 `master` 分支后，现有部署流程会更新线上写作台；若浏览器仍显示旧工具栏，请强制刷新页面。
